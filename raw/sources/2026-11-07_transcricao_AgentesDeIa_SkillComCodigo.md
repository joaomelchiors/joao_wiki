Skill com Código

Pessoal, nós vamos agora criar uma skill quase do zero, certo? Eu vou criar aqui uma nova sessão para a gente interagir em uma sessão diferente, já que agora estamos criando um outro exemplo. Eu vou criar a skill apenas no Claude, depois eu copio, dou um Ctrl + C, Ctrl + V e jogo na pasta do ChatGPT, certo? O nome da skill vai ser “inverter-texto”. E aí nós vamos fazer o seguinte: dentro dessa pasta inverter-texto, eu vou criar de novo um arquivo chamado SKILL.md, e tem que ter esse nome, certo, gente? SKILL com letras maiúsculas, ponto md, que é o padrão que ele vai usar como referência. Eu nunca testei com letras minúsculas, mas em todos os exemplos que vejo no mercado as pessoas criam com letras maiúsculas, então a gente vai seguir esse padrão.

Então vamos lá. Eu vou colocar de novo três tracinhos, depois mais três tracinhos, e entre eles vou colocar “name:” e “description:”. No nome, vou colocar o nome da pasta, certo? “inverter-texto”. Na descrição, vou colocar: “Skill responsável por inverter o texto fornecido pelo usuário usando um código em JavaScript.” Escolhi JavaScript porque é a linguagem com que tenho mais familiaridade, embora a gente não vá programar aqui. E aí vou colocar o seguinte: “Use a resposta da IA e chame o código que está no arquivo inverter-texto.js para inverter o texto fornecido pelo usuário. O código em JavaScript deve receber um texto como entrada e retornar o texto invertido como saída.”

Beleza. O que nós vamos fazer agora? Eu vou pegar esse nome de arquivo e criar aqui dentro um arquivo, em New File. Vou criar esse arquivo em branco, certo? E o que eu vou pedir para a IA fazer nesse caso? Eu vou referenciar esse arquivo aqui dentro do Claude, o inverter-texto.js, e vou dizer o seguinte: “Crie um código que inverte o texto completamente.” Beleza. Eu não vou criar esse código, não me interessa criar esse código, não é um curso de programação. Eu estou mostrando que a gente pode criar skills que chamam códigos, tá?

E aí ele vai criar esse código para a gente. Não vou me preocupar com o que está dentro dele. O fato é que nós vamos usar essa skill para testar. Uma vez criado o código, vou fechar, certo? Vou copiar essa pasta para dentro da pasta skills do outro lado. Basta você clicar na pasta skills e dar um Ctrl + V (ou Command + V no Mac), depois de ter copiado com Ctrl + C (ou Command + C). Ele vai copiar a pasta completa com as suas instruções. Beleza, agora nós temos duas skills dentro de .agents/skills, que é a do ChatGPT, e duas skills dentro de .claude/skills, que é a do Claude. Vocês estão percebendo que eles são muito parecidos? A forma como eles trabalham é praticamente a mesma, com exceção de alguns detalhes aqui e ali.

Agora nós podemos fazer o seguinte: eu posso abrir uma nova sessão ou mesmo limpar a atual. Vamos abrir uma nova sessão. Ele está perguntando se eu quero testar. Eu vou simplesmente dizer que não e vou parar essa sessão. E nós vamos fazer o seguinte: eu vou chamar aqui o reload skills para ele recarregar as skills. Vou chamar o inverter-texto, que ele já encontrou, e vou escrever, por exemplo: “Me fale sobre a Dinamarca.”

Beleza. Aí eu vou pedir para ele falar resumidamente. Eu coloquei um script para ser executado depois desse processo. E o que é para ele fazer? Nesse caso, a gente precisa ter aquela ferramenta que eu comentei com vocês, o Node.js, que é a ferramenta usada para interpretar essa linguagem. Se não tiver, provavelmente vai dar um problema. E aí ele gerou essa resposta maluca aqui para a gente, certo? Que é o texto ao contrário: “A Dinamarca é um país conhecido pela...”

Sei lá, né? Beleza, gerou aqui o texto invertido, porque a gente pediu para ele fazer isso usando o código. A mesma coisa vai acontecer no ChatGPT. Achei que ele não teria carregado ainda, mas já carregou, entendeu? Foi esperto: eu não reiniciei e ele carregou o inverter-texto. Vou fazer a mesma pergunta: “Me fale resumidamente sobre a Dinamarca.” Ele vai pegar essa skill de inverter texto e aplicar a lógica do código. Dá para fazer muita coisa com linguagem de programação, gente.

Você pode fazer quase um sistema usando a inteligência artificial. Lembra daquele exemplo que eu mostrei? A não ser que eu tenha tirado do ar, né? Era um exemplo do Instagram em que você baixa a lista dos vídeos, ordena pelos mais populares, baixa os vídeos e transcreve. Tudo aquilo foi feito usando skills por baixo, com código que pode ser executado diretamente no seu computador. O ChatGPT fez a mesma coisa: pegou a minha skill inverter-texto. Eu pedi “Me fale resumidamente sobre a Dinamarca”, ele trouxe uma resposta, passou pelo código que eu tinha colocado e, no final, entregou a resposta com o texto completamente invertido.

Eu sei que isso aqui não é algo extremamente útil, mas, como eu falei para vocês, a gente não está fazendo projetos. Nós estamos vendo os princípios, os pilares, como isso funciona, de forma a te dar poder para usar a IA e automatizar aquilo que você sonhar. Então, vou ficar por aqui nesse segundo exemplo, em que criamos a nossa segunda skill para mostrar como você pode usar código. E uma coisa importante: dentro dessa pasta inverter-texto tem dois arquivos. Gente, poderia ter 50. Poderia ter 50 mil arquivos dentro dessa skill. Não tem problema.

O arquivo SKILL.md é só o arquivo de entrada. Esse arquivo tem que existir. Você pode ter só ele, zero problema, tá? Mas ele é a porta de entrada para fazer qualquer outra coisa. Dentro dele você vai colocar o prompt ou parte do prompt. Você também pode colocar exemplos, como eu falei. “Ah, Léo, eu quero colocar os exemplos em um arquivo separado.” Zero problema. Basta dizer no SKILL.md: “Todos os exemplos estão no arquivo exemplos.md.”

E eu não cheguei a comentar com vocês: por que essa extensão .md, Léo? Não poderia ser .txt? Não. O .md é a extensão do Markdown. Ele tem algumas características diferentes de um arquivo de texto comum, mas, no final das contas, é um arquivo de texto. Você escreve nele normalmente, só que ele tem essa extensão .md, que a gente vai usar muitas vezes durante o curso. Depois eu explico melhor como ele funciona, mas basicamente você consegue colocar títulos e alguns elementos, como negrito e itálico, usando alguns símbolos dentro do texto.

Mas isso não vem ao caso agora. Depois a gente fala mais sobre isso. O fato é que nós criamos duas skills para você ver como criar uma skill sem código, que usa apenas o modelo de IA, e uma skill que chama um código para fazer um trabalho determinístico. Uma questão importante: quando a IA trabalha usando apenas o modelo, é possível que a inversão do texto não saia 100% correta, porque ela usa um processo probabilístico para te dar uma resposta.

Já o código é preciso. Se você for trabalhar com operações matemáticas, é muito importante tomar cuidado para a IA não cometer erros nas contas, já que ela não é especialista em fazer operações matemáticas, mas uma linguagem de programação é. Então, se você fizer as operações matemáticas usando código, a precisão é muito maior. Use a IA naquilo em que ela é forte. Já um código de programação é determinístico, ou seja, sempre vai ter o mesmo resultado para uma mesma entrada, e talvez seja melhor em alguns contextos. Ter os dois à disposição é a melhor coisa que você pode fazer quando for criar as suas skills, tá bom?
