No contexto de desenvolvimento com agentes de IA, uma skill é um pacote de instruções conhecidos, o pacote de instruções, conhecimento e procedimentos que ensinam um agente a executar melhor um tipo específico de tarefa. Pense nela como uma capacidade especializada plugável. Então, a capacidade de criar um texto publicitário divertido, a capacidade de criar um título de um vídeo do YouTube, a capacidade de criar um padrão para projeto na sua aplicação, tá? Então, criar e revisar planilha, gerar apresentações, editar documentos, trabalhar com PDF, seguir um padrão arquitetural específico, como o DDD ou arquitetura limpa, usar uma API interna, criar uma regra de estilo de código da sua empresa. Então, você tem uma skill que faz uma validação para saber como que as nomenclaturas de um determinado código devem ser criadas baseado no padrão da tua empresa, tá? Uma skill normalmente contém coisas como instruções sobre quando ela deve usar, passos recomendados para realizar a tarefa, padrões, restrições, boas práticas, exemplos, scripts, templates ou arquivos auxiliares. A diferença entre uma skill e um simples prompt é que a skill tende a ser reutilizável, tá? Organizada e acionável, em vez de explicar tudo de novo a cada conversa. Isso é importantíssimo, gente, tá?
