O segundo passo é imaginar que você tem uma skill híbrida. Então, a ideia é que você vai fazer um processo híbrido, ou seja, parte da skill ela é determinística, ela é fixa, tem um código que vai ser executado e parte o agente vai decidir como fazer. Por exemplo, você vai criar lá uma skill para criar um módulo da sua aplicação. Então, você pode ter parte do processo sendo feito determinístico e parte você pedindo para o agente manipular determinados arquivos seguindo um padrão específico para ele fazer algo que já existe no teu projeto e você conseguir mesclar uma parte dessa funcionalidade. Ou seja, você está fazendo uma forma de criar ali a tua skill híbrida.
