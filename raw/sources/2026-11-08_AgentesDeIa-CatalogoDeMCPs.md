Links para baixar MCPs prontos na internet
Antes de baixar qualquer MCP, verifique a procedência — é possível usar os Links Oficiais no fim desta página para confirmar quem publicou.

# Catálogos de MCPs

    https://smithery.ai — Um catálogo com busca visual e botão de instalar, onde boa parte das conexões funciona apenas com login, sem precisar instalar nada no computador.
    https://www.pulsemcp.com/servers — Um catálogo com descrições em linguagem do dia a dia ("conecte seu Notion", "leia seus e-mails"), o mais fácil de navegar para quem está descobrindo o assunto agora.
    https://mcp.so — O maior catálogo disponível, com busca por categoria, ideal para responder à pergunta "será que existe uma conexão pronta para o programa que eu uso?".

# Lista de MCPs feitas pela Comunidade

    https://github.com/punkpeye/awesome-mcp-servers — A maior lista comunitária de servidores MCP organizada por categoria, com versão traduzida para português.
    https://github.com/wong2/awesome-mcp-servers — Uma curadoria mais enxuta e seletiva que a anterior, ideal para quem está começando e se perde em listas gigantes.
    https://github.com/appcypher/awesome-mcp-servers — Outra lista comunitária extensa, com destaque para a boa organização por categorias de uso.
    https://github.com/tolkonepiu/best-of-mcp-servers — Cerca de 400 servidores **ranqueados por popularidade** e atualizados semanalmente, o melhor recurso para responder "qual eu devo usar?".

# Links Oficiais

    https://registry.modelcontextprotocol.io — O catálogo oficial e centralizado de servidores MCP, onde cada publicação é vinculada a um domínio ou conta GitHub verificada, garantindo a procedência.
    https://github.com/modelcontextprotocol/servers — Repositório oficial com os servidores de referência (filesystem, git, fetch, memory) mais uma lista curada de integrações oficiais de empresas como GitHub, Stripe e Notion.
